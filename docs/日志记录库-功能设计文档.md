# 日志记录库 - 功能设计文档

> 版本：v1.0
> 创建时间：2026-07-15
> 仓库地址：https://github.com/Atian10/log-record

---

## 一、项目概述

跨平台日志记录库，支持 Android、Windows 桌面、Windows 服务器、Linux 服务器四大场景。提供日志写入、查询、导出、自动清理等完整能力，可作为基础组件被其他项目复用。

### 设计原则

- **核心模块零平台依赖**：`log-core` 纯 Java SE 实现，所有平台共用
- **存储统一为数据库**：唯一持久化存储为数据库（Android Room / JDBC SQLite）
- **业务方自主上报**：库内不实现网络上报，业务方通过查询 API 取日志后自行上报
- **最小化原则**：只实现确认的功能，不过度设计

## 二、核心功能

| 编号 | 功能 | 说明 |
|------|------|------|
| 1.1 | 多级别日志写入 | 支持 DEBUG / INFO / WARN / ERROR / FATAL 五个级别 |
| 1.2 | 自定义日志类型 | 内置 NETWORK / UI / DATABASE / BUSINESS / SYSTEM 五种预设，业务方可传字符串无限扩展 |
| 1.3 | Tag 标签 | 每条日志可携带 Tag |
| 1.4 | 异常堆栈记录 | 支持携带 Throwable，异常存独立表，与日志表完全独立 |
| 1.5 | 线程信息记录 | 自动捕获线程名和线程ID |
| 1.6 | 时间戳记录 | 自动捕获毫秒级时间戳（UTC 存储） |
| 1.7 | 全级别强制写入 | 所有级别日志强制写入数据库，不支持级别门槛过滤 |
| 1.8 | 方法名/行号记录 | 可配置开关，默认关闭。开启后自动捕获调用方的类名、方法名、行号 |
| 1.9 | 用户内容与系统字段分离 | 系统字段（时间/级别/类型/Tag/线程/方法行号）自动填充到独立列；用户只关心写入业务内容 |
| 1.10 | 用户内容支持键值对 + 纯文本混合 | 用户可传 `Map<String, String>` 业务字段 + 一个 message，数据库分开存储 |
| 1.11 | 版本标签记录 | 初始化时全局配置 `version_tag`，记录在日志表系统字段列，可选填，未配置则为 null。语义由业务方自定义（App版本/模块版本/固件版本等）。支持运行时动态修改 |
| 1.12 | 磁盘空间/数量上限保护 | 写入前检查，超限触发同步清理；清理不够时丢弃新日志+告警 |
| 1.13 | 异常独立写入 | 异常写入独立表，与日志表无外键关联；提供便捷方法 `e(tag, msg, throwable)` 内部拆为两条独立记录 |

### 日志级别定义

| 级别 | 数值 | 说明 |
|------|------|------|
| DEBUG | 1 | 调试信息 |
| INFO | 2 | 普通信息 |
| WARN | 3 | 警告信息 |
| ERROR | 4 | 错误信息 |
| FATAL | 5 | 致命错误 |

### 预设日志类型

| 类型 | Code | 说明 |
|------|------|------|
| NETWORK | NETWORK | 网络日志 |
| UI | UI | 界面日志 |
| DATABASE | DB | 数据库日志 |
| BUSINESS | BUSINESS | 业务日志 |
| SYSTEM | SYSTEM | 系统日志 |

业务方自定义类型：直接传字符串即可，无需注册。

## 十五、数据库表结构

### 日志主表 log_record

```sql
CREATE TABLE log_record (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    timestamp       INTEGER NOT NULL,      -- 系统字段：时间戳（UTC 毫秒）
    level           INTEGER NOT NULL,      -- 系统字段：级别（1-5）
    type            TEXT NOT NULL,         -- 系统字段：类型
    tag             TEXT NOT NULL,         -- 系统字段：Tag
    thread_name     TEXT,                  -- 系统字段：线程名
    thread_id       INTEGER,               -- 系统字段：线程ID
    method_name     TEXT,                  -- 系统字段：方法名（可配置捕获）
    line_number     INTEGER,               -- 系统字段：行号（可配置捕获）
    message         TEXT,                  -- 用户内容：纯文本
    user_fields     TEXT,                  -- 用户内容：键值对（JSON 存储）
    version_tag     TEXT,                  -- 系统字段：版本标签（可空）
    has_exception   INTEGER DEFAULT 0      -- 系统字段：是否伴随异常（仅标记）
);

CREATE INDEX idx_log_timestamp ON log_record(timestamp);
CREATE INDEX idx_log_level ON log_record(level);
CREATE INDEX idx_log_type ON log_record(type);
CREATE INDEX idx_log_tag ON log_record(tag);
CREATE INDEX idx_log_version_tag ON log_record(version_tag);
```

### 异常表 exception_table（独立，无外键）

```sql
CREATE TABLE exception_table (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    timestamp       INTEGER NOT NULL,      -- 独立时间戳
    exception_class TEXT,                  -- 异常类名
    exception_msg   TEXT,                  -- 异常消息
    stack_trace     TEXT,                  -- 完整堆栈
    log_tag         TEXT                   -- 弱关联：记录时的 tag（可选）
);

CREATE INDEX idx_exception_timestamp ON exception_table(timestamp);
CREATE INDEX idx_exception_log_tag ON exception_table(log_tag);
CREATE INDEX idx_exception_class ON exception_table(exception_class);
```

## 十六、API 使用示例

> 注：以下示例使用实际实现 API。平台初始化入口、Builder 方法名、回调方法签名均与代码一致，详见各平台示例代码（`log-sample` / `log-sample-android`）。

### 初始化配置（Android 平台）

```java
// 注意：传入的是 LogConfig.Builder（不是 LogConfig），平台适配层会注入 storage/exceptionStorage
LogConfig.Builder builder = LogConfig.builder()
    .consoleEnabled(true)                       // Android 开启 Logcat 输出（自动用 LogcatStorage 装饰）
    .captureMethodLine(false)                   // 方法名/行号捕获（默认关）
    .versionTag("1.2.3")                        // 版本标签（可选）
    .queueCapacity(2048)                        // 异步队列容量
    .batchSize(100)                             // 批量写入阈值
    .batchIntervalMillis(1000L)                 // 批量写入周期
    .formatter(new DefaultFormatter())          // 格式化器（可选，null 则用 DefaultFormatter）
    .exportEncoding(ExportEncoding.UTF_8)       // 导出编码（默认 UTF_8）
    .cleanPolicy(CleanPolicy.builder()          // 清理策略（默认关闭，需显式开启）
        .enable(true)
        .keepDays(7)
        .maxDbSizeMB(500)
        .maxRecordCount(100000)
        .cleanIntervalHours(24)
        .build())
    .exceptionCleanPolicy(CleanPolicy.builder() // 异常表独立清理策略
        .enable(true)
        .keepDays(30)
        .build());

AndroidLogInit.init(context, builder);          // 自动注入 RoomStorage/RoomExceptionStorage
```

### 初始化配置（桌面/服务器平台）

```java
// dbPath 为 SQLite 数据库文件路径，业务方自行指定
DesktopLogInit.init("/var/log/app/log_record.db", builder);   // 自动注入 JdbcStorage/JdbcExceptionStorage
```

### 写入日志

```java
// 基础写入（便捷方法，type 默认 SYSTEM）
LogManager.get().d("tag", "调试信息");
LogManager.get().i("tag", "普通信息");
LogManager.get().w("tag", "警告信息");
LogManager.get().e("tag", "错误信息");
LogManager.get().f("tag", "致命错误");

// 携带异常（便捷方法，内部拆为两条独立记录）
LogManager.get().e("LoginActivity", "登录失败", exception);
// → 写一条 ERROR 日志（has_exception=1）
// → 写一条异常记录（log_tag="LoginActivity"）

// 携带用户内容（键值对 + 纯文本）
Map<String, String> userFields = new HashMap<>();
userFields.put("userId", "10086");
userFields.put("ip", "192.168.1.1");
userFields.put("errorCode", "AUTH_FAIL");
LogManager.get().log(LogLevel.ERROR,
    StandardLogType.NETWORK.code(),
    "LoginActivity",
    "用户登录失败",
    userFields);

// 携带用户内容 + 异常
LogManager.get().log(LogLevel.ERROR,
    StandardLogType.BUSINESS.code(),
    "UserService",
    "查询用户资料失败",
    userFields,
    exception);

// 异常独立写入（不伴随日志）
LogManager.get().recordException(exception, "LoginActivity");

// 立即触发落盘（生产环境无需频繁调用）
LogManager.get().flush();
```

### 查询日志

```java
// 组合条件查询
List<LogRecord> records = LogManager.get().queryLogs(
    LogQuery.builder()
        .level(LogLevel.ERROR)
        .type(StandardLogType.NETWORK.code())
        .tag("LoginActivity")
        .keyword("失败")
        .fromTime(startTime)
        .toTime(endTime)
        .userField("errorCode", "AUTH_FAIL")   // 按用户键值对查询
        .versionTag("1.2.3")                   // 按版本标签查询
        .orderBy(OrderBy.DESC)
        .offset(0)
        .limit(100)
        .build()
);

// 聚合统计（按级别/类型/Tag 维度）
LogStatistics stats = LogManager.get().statistics(
    LogQuery.builder()
        .fromTime(today)
        .build()
);

// 独立查询异常（与日志表完全独立）
List<ExceptionRecord> exceptions = LogManager.get().queryExceptions(
    ExceptionQuery.builder()
        .tag("LoginActivity")
        .fromTime(startTime)
        .toTime(endTime)
        .exceptionClass("NullPointerException")
        .orderBy(OrderBy.DESC)
        .build()
);
```

        @Override
        public void onFailure(Throwable error, int exportedCount) {

### 运行时动态配置

```java
// 通过 LogConfigUpdater 动态修改（CAS 整体替换，无需 apply，立即生效）
LogConfigUpdater updater = LogManager.get().getConfigUpdater();
updater.updateVersionTag("1.2.4");              // 动态修改版本标签
updater.updateCaptureMethodLine(true);          // 开启方法名/行号捕获
updater.updateConsoleEnabled(true);             // 开启控制台输出（注意：Android/桌面端已由装饰器处理，此项实际不生效）
updater.updateCleanPolicy(newCleanPolicy);      // 修改清理策略
updater.updateExportEncoding(ExportEncoding.UTF_8);

// 修改清理策略后需调用 refreshCleanPolicies() 同步到定时任务
LogManager.get().refreshCleanPolicies();
```
